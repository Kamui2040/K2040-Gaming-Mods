# K2040 Gaming Mods Project Context

## Current Gaming website state

- K2040's Quick Attach Menu `0.5.221` is published on GitHub; Nexus Mods still lists `0.5.220`. The featured project page and five-language updates feed link to the new GitHub release and the existing Nexus page. They summarize the Hunting Rifle fix, clearer Quick Menu navigation, scrolling for clipped items, category ordering, and optional movement and mouse-look while the menu is open. The tester confirmed movement and ordering in game. The shared Fallout 4 artwork is unchanged.
- ECO Quick Menu Additions remains listed as a released Fallout 4 project but is no longer the featured landing-page project.

### WoW WotLK

- The Gaming landing page uses one consolidated WoW WotLK Addons category card rather than separate top-level addon cards.
- The WoW WotLK category page is `projects/wow-wotlk.html` and uses the shared 3:1 WotLK hero artwork.
- Loot & Salvage is the first addon entry inside the WoW WotLK category and uses the shared category card artwork.
- Loot & Salvage has a dedicated project-detail view through `projects/project.html?project=loot-and-salvage`, with the Nexus Mods `0.1.0` link and current GitHub `0.2.0` pre-release link. Its built-in presentation choices and optional AddOnSkins requirement for ElvUI mode are documented in every supported language.
- GM Genie is the second addon entry and has a dedicated project-detail view through `projects/project.html?project=gm-genie`, its current Nexus Mods `1.1` main-file link, localized built-in skin-selector details, and six interface screenshots.
- Website-rendered titles, descriptions, tags, status, actions, frames, and localization remain separate from the source artwork.

### Fallout 4 — Quest Journal

- Quest Journal `0.0.2` is published on GitHub and listed in the Gaming Mods project catalog. Its card and project header use the same Fallout 4 artwork as Quick Attach Menu and the other Fallout 4 projects.
- The project page includes a gallery with three user-supplied screenshots in this order: Mini tracker, Full journal, Settings. The original screenshots were converted to WebP to keep the site fast; the main game mod artwork remains unchanged.
- The page links to the official GitHub release, source repository and Nexus Mods page, with English, German, Portuguese, Spanish and French descriptions, features and screenshot captions.

- Quest Journal is also available on Nexus Mods (Fallout 4 mod 110911). A single November 3 release announcement appears in the Gaming updates feed, with links to the project page, Nexus Mods and GitHub release, translated into all five site languages.
- The gallery now places image names above the screenshots and centers the portrait screenshot card beside the full journal and settings cards. Widescreen previews keep their natural proportions; on phones the gallery stacks vertically. Other mod galleries are unchanged.
