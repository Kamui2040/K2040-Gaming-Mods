# K2040 Gaming Mods Repository Instructions

## Purpose

This public repository contains the K2040 Gaming Mods website, public project information, and authorized website assets.

## Keep the repository public-safe

- Everything committed here must be safe to publish.
- Do not store passwords, tokens, signing or recovery material, personal data, private URLs or IDs, machine-specific paths, private QA, backups, or maintainer-only records.
- Keep only authorized or properly licensed assets, with required attribution preserved.

## Repository work

- Keep `main` stable and use focused branches and pull requests for changes.
- GitHub Actions and other cloud CI are disabled and must not be used.
- Routine website and GitHub Pages updates caused by normal repository changes are allowed.
- Social posts, announcements, ads, account changes, or scheduled publication remain separate and require explicit approval.

## Website content

- Use simple, natural public-facing language.
- Keep all supported languages consistent when visible text changes.
- Gaming project and Gaming update data should have one authoritative source in this repository.
- Preserve intentional source order when multiple update entries share the same date.
- Keep landing pages lightweight and suitable for mobile and weaker devices.

## Validation

Before accepting website changes, check relevant links, local assets, desktop and mobile navigation, localization, and `git diff --check`.
